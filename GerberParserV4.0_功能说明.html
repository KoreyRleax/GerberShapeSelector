一句话定位：打开 Gerber 底图 → 在其上挑出需要的焊盘/针位（选点）→ 存成模板（circles.json + 同目录 Gerber 底图）， 供下游设备按模板定位。核心工作量在"挑点"，所以选点交互是这个软件的主战场。

一、界面分区

区域标题内容
左侧主画布kWindowControl1 956×928 的矢量画布，纯黑背景。Gerber 光圈、模板点、已选点、框选限定框都在这里绘制
画布上沿悬浮工具栏 新增贴在画布顶部的半透明浮层，放高频动作：单选 / 多选、框选、解除限定、清空选点、底图开关。控件库自动同步 ViewPadding 做"视口让位"——只压留白、不压图
画布右键上下文菜单 新增右键未拖动时弹出（拖动则是平移）。内容随上下文变化：对光标下那个点的操作、框选限定、视图、清空选点。同类操作在这里可直接用，不必先切单选 / 多选
右上第 1 组基础操作 重置图像、水平翻转、垂直翻转、参数设置
右上第 2 组模板文件操作 打开 Gerber 文件、文件名、保存、另存到、加载、底图显示（是/否）
右上第 3 组图层 空面板预留位，目前无任何子控件
底部状态栏 点击方式 / 已选数量 / 框选限定状态 / 保存与加载的完整路径 / 各种操作反馈
「选点操作」面板已整体移除。它原来的 5 个控件（框选区域、清除区域、清空选点、单选、多选）全部迁到了悬浮工具栏 —— 功能一个没少，但常用操作不再需要把鼠标移到右侧面板去。右侧留下的都是低频 / 配置类： 文件操作、视图翻转、参数设置。

二、功能清单

1. 文件与模板

功能入口说明
打开 Gerber 文件按钮 / btnOpenFile 解析 Gerber，得到光圈表（形状 + 尺寸 + 全部位置）。解析后进入「Gerber 模式」：清空已选点、清空框选限定
底图显示 开 / 关工具栏 底图 / 单选 只看模板点时，可关掉 Gerber 底图叠加（作用于模板模式下的绘制）。两处入口是同一份状态，互相同步
保存模板按钮 / btnSaveTemple 就地保存：当前有模板归属就覆盖它所在目录（在哪加载的就回哪去）。无归属（刚解析完 Gerber）才落到「参数设置」里的模板路径。落点不同时弹确认框并显示完整路径
另存到按钮 / btnSaveAs 选任意目录另存一份；存完会把"当前模板归属"指到新位置，之后「保存」写回新位置（原实现漏了这一步，会写回旧目录）
加载模板按钮 / btnOpenTemple 选 circles.json；自动加载同目录的 Gerber 底图（优先文件名与文件夹名匹配的，否则取最近修改的），恢复镜像状态与已选点
启动记忆新增自动 每次打开 Gerber 或加载模板都会记住类型 + 路径，下次启动程序自动恢复，不用重新找文件（详见下方）
启动记忆（自动恢复上次的工程）
· 记的是最后一次打开的工程：LastProjectKind（gerber / template） + LastProjectPath（Gerber 文件全路径 / 模板文件夹全路径），存在 Properties.Settings 里
· 启动时按类型走对应入口：模板 → 直接按文件夹加载；Gerber → 直接按路径解析
· 路径已失效时不反复报错：清掉记录并在状态栏说明一句，下次启动就当没这回事
· 附带好处：打开 Gerber 对话框的起始目录也跟着上次的位置走（原来是写死的一个绝对路径）

模板目录的内容

模板A\
  circles.json     模板点数据（TemplateInfo + Shapes）
  <底图>.gbr       保存时自动从源路径复制过来（已存在则跳过）

3. 选点（核心）

操作入口说明
左键点选画布左键任何时候都能点，不需要先进入任何模式（旧版有个"选点模式"门禁，退出后点击无反应，已取消）
单选 / 多选工具栏 toggle决定左键点一下的语义：切换这一个点，还是切换同类的一批点（按光圈 ID 判定同类型）
框选工具栏 / Q / 右键菜单拉框松手 → 框内图形一次性全部选中（累积语义，只增不减，可多次框选不同片区）
框选限定自动生效 框选后画面保留红框。此时多选只在框内扩散同类点；点框外自动解除限定（框消失，恢复全板）
解除限定工具栏 / Esc / 空格 / 右键菜单清掉红框，多选回到全板范围
清空选点工具栏 / 右键菜单二次确认后清空全部已选点
撤销框选Ctrl+Z回滚上一次框选造成的选择变化（栈深 20）。逐点选点不入栈，所以不会误伤你后来点出来的结果
选中 / 取消此点右键菜单新增直接切换光标下那一个点
选中 / 取消同类全部右键菜单新增切换同类的一批点 —— 省掉"先去工具栏切多选"这一步
操作说明F1弹出完整操作说明
框选限定的规则（框就是指示灯，框在不在 = 限定生不生效）
· 框在 → 多选只切换框内同类点，框保留
· 点框外 → 自动解除限定（框消失），本次按全板切换同类
· 点击命中永远不受限定影响 —— 框外一直点得中，不存在"点了没反应"
· 单选 / 多选行为一致，没有"哪种点击方式才会解除"的例外规则

四、性能设计要点

要点说明
全量图形缓存_allShapes 只在解析 Gerber / 加载模板后构建一次。原实现每次鼠标点击都重建 15,359 个对象并逐个在已选集合里线性查（约 2,960 万次比较 / 次点击）
视口裁剪每帧只绘制落在可见范围内的图形，成本从"全图 15,359"降到"可见数"
包围盒缓存_contentBounds 算一次复用。原实现每帧对每个图形各算一次，退化成 O(N²)（约 2.36 亿次迭代/帧）
框选去重框选全选时用一次性构建的 HashSet（键 (X,Y,Shape)，与缓存构建时的索引键一致）→ O(n+m+k)。若沿用逐点线性查会退化成 O(k·n)，3,852 点全选约 1,480 万次比较
单次刷新框选完成只刷一帧（状态先改完，绘制统一走 RefreshKWindow）

五、光圈配色

按光圈索引 ai % 17 循环取色。背景是纯黑，因此配色表已剔除对比度不足的颜色（阈值取 4.5:1，比非文本图形常用的 3:1 更严 —— 因为光圈是描边绘制的细轮廓）：

已剔除对纯黑对比度理由
blue (0,0,255)2.44:1低于 4.5:1 阈值，黑底上看不清
dark olive green (85,107,47)3.53:1
dim gray (105,105,105)3.83:1
slate blue (106,90,205)3.96:1

剔除后色数减少，又补入两个高亮色凑回 17 色（位置刻意用来隔开邻近色相：violet 插在两个灰色之间、gold 插在冷紫与暖珊瑚之间）：

red, green, gray, violet, light gray, cyan, magenta, yellow,
medium slate blue, gold, coral, spring green, orange red, orange,
pink, cadet blue, white

七、本轮（2026-09-18）的设计变更

变更原因
框选改为「框完即选」原设计里框选只缩小"点击可达范围"，用户必须再逐个点；且框外点击静默失效，必须先"清除区域"
引入「框选限定」单纯取消区域会丢掉旧设计真正有用的部分 —— 在区域内按类型批量操作（区域里 A/B 要、C 不要时，一次点掉 C）。改法：保留"限定同类扩散"，去掉"拦截点击"
去掉选点模式门禁左键本意就是选点，加模式后"退出模式就点不了"，容易被当成软件故障
删除「锁定」按钮它的全部功能就是上面那个模式开关，且按钮文字逻辑颠倒
删除「开始选点」按钮职责已随模式取消而消失；操作说明改挂 F1
修正模板保存归属「另存到」后未更新当前模板归属，导致再点「保存」写回旧目录
剔除黑底看不清的光圈色见第五节
新增画布悬浮工具栏高频选点操作从右侧面板搬到画布上，手不离开图。控件库自带"视口让位"（只压留白不压图）
新增右键上下文菜单「同类操作」不必先切「多选」；视图类与清空也顺手可达
移除「选点操作」面板5 个控件全部迁入工具栏后该分组已无存在意义，右侧只留低频 / 配置类
新增启动记忆重启后自动打开上次的工程，见第一节
